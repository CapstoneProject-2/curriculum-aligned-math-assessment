# 결과 파일 안내

실행 과정에서 생성되는 엑셀 및 CSV 결과 파일은 Git에 포함되지 않도록 설정되어 있습니다.

## 채점 결과

부분점수 기본 비교 실험은 다음 파일을 생성합니다.

- `grading_부분점수_채점_baseline(v1).xlsx`: 학생 답안별 채점 결과
- `judge_grading_부분점수_채점_baseline(v1).xlsx`: 자동 채점 결과에 대한 대형언어모델 기반 심사자의 평가

## 적절 채점 비율

유효한 대형언어모델 기반 심사자 판정만 사용하여 다음과 같이 계산합니다.

```text
적절 판정 수 / (적절 판정 수 + 부적절 판정 수)
```

`<judging_conclusion>` 태그가 정확히 하나이고 그 값이 `적절` 또는 `부적절`인 경우만 유효한 판정으로 처리합니다. 태그 누락·복수 태그·잘못된 값·API 호출 오류가 발생하면 최대 2회 추가 시도합니다. 계속 실패한 행은 별도로 집계하며 위 비율의 분모에 포함하지 않습니다.
