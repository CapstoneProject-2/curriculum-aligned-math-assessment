# 프롬프트 안내

각 프롬프트 파일에는 버전, 사용 시기, 모델, 직전 버전 대비 변경 내용과 변경 이유를 기록합니다. 시스템 프롬프트와 사용자 프롬프트는 실제 실험에서 사용한 원문을 코드 블록 안에 보존합니다.

## 프롬프트 목록

| 기능 | 파일 | 조건 |
| --- | --- | --- |
| 문항 생성 | `generation/` | 담당자 정리 예정 |
| 문항 검증 | `validation/` | 담당자 정리 예정 |
| 이진 채점 기준 생성 | `rubric/binary.md` | 이진 채점 기준 |
| 부분점수 채점 기준 생성 | `rubric/partial_credit.md` | 배점이 포함된 분석적 채점 기준 |
| 이진 채점 | `grading/binary_v1.md` | 기본 조건 |
| 이진 채점 | `grading/binary_v2.md` | 프롬프트 최적화 조건 |
| 부분점수 채점 | `grading/partial_credit_v1.md` | 기본 비교 조건 |
| 부분점수 채점 | `grading/partial_credit_v2.md` | 프롬프트 최적화 조건 |
| 학생 피드백 | `feedback/feedback.md` | 채점 결과 기반 피드백 |
| 채점 결과 평가 | `judge/llm_as_judge.md` | 채점의 수학적·논리적 적절성 판정 |

채점 모듈의 파인튜닝 조건은 프롬프트 최적화 조건과 같은 프롬프트를 사용하므로 별도의 v3 프롬프트 파일을 두지 않습니다. 조건별 상세 변경 내용은 루트의 `CHANGELOG.md`에서 확인할 수 있습니다.
