# 데이터 안내

평가 데이터와 생성 결과는 접근 권한 및 재배포 조건을 확인해야 하므로 이 저장소에 포함하지 않습니다. 사용자는 적법하게 확보한 데이터를 아래 형식에 맞춰 준비해야 합니다.

## 채점 입력 데이터

부분점수 채점 실행에는 다음 정보를 포함한 엑셀 파일이 필요합니다.

- 문항 식별자와 답안 번호
- 학년, 단원, 난이도 등 문항 메타데이터
- 문제, 해설, 정답
- 채점 기준
- 학생 답안과 정답·오답 라벨

정확한 열 이름과 순서는 `src/grading/run_partial_credit_baseline.py`의 `GRADING_COLUMNS`에 정의되어 있습니다. 필요한 열이 없으면 스크립트가 실행 전에 오류를 표시합니다.

논문의 부분점수 채점 평가셋은 원본 400개 답안에서 `유리수와 순환소수` 단원 40개를 제외한 360개 답안으로 구성됩니다. 해당 제외 및 행 수 확인은 실행 코드에 포함되어 있습니다.

## 비공개 자료

다음 자료는 공개 저장소에 포함하지 않습니다.

- 평가용 원본 문항과 학생 답안
- 전문가 검토 및 평가 기록
- 파인튜닝 학습 데이터
- 비공개 파인튜닝 모델 식별자

허가된 모델을 사용할 때는 각 실행 스크립트의 `--model` 인자로 모델 식별자를 전달할 수 있습니다.

## 문항 생성 데이터

문항 생성에 사용한 데이터 출처, 전처리 과정 및 최종 문항 ID 목록은 문항 생성 담당자가 정리하여 추가할 예정입니다.
